# החומר לרואה החשבון, בשיחה אחת עם Claude

מורידים את הדוחות מהבנק, מהכרטיסים ומתוכנת החשבוניות, ו-Claude מסדר הכול: מה נכנס, מה יצא, ועל מה חסרה קבלה.
המסך מציג את התמונה, ואתם רק מסמנים.

## איך מתחילים (דקה אחת)
1. מורידים את אפליקציית Claude (claude.ai/download), פותחים את הלשונית Code ובוחרים תיקייה ריקה.
2. מדביקים: **תוריד את github.com/haimchernin/roeh-cheshbon ותתחיל**

או, אם כבר הורדתם את התיקייה: פותחים בה את Claude Code ואומרים: "בוא נסגור את החודש". בפעם הראשונה Claude שואל אם לפתוח תיקייה חדשה לעסק או להתחבר לקיימת, ושואל כמה שאלות על העסק. מהחודש השני הוא כבר זוכר.
3. Claude אומר בדיוק מה להוריד, כמה זמן זה לוקח, ואיפה לשים.

## מה יש פה
- `מסך.html`: המסך של התקופה. מציג בלבד.
- `שנה.html`: השנה שלי. כמה נכנס ויצא בכל חודש, ותחזית לסוף השנה. המודל פשוט ופתוח: פונקציה אחת, `forecast`.
- `make_report.py`: הדוח לרואה החשבון. PDF מסכם, PDF אחד עם כל הקבלות, ו-CSV.
- `serve.py`: שרת קטן שרץ רק על המחשב שלכם (Python, בלי התקנות). שומר את מה שמסמנים ומעדכן את המסך לבד.
- `CLAUDE.md`: ההוראות ל-Claude.
- לכל תקופה Claude פותח תיקייה (למשל `2026-09-10/`) עם `קבצים/`, `סרוקות/`, `קבלות/` והדוח לרואה החשבון.

## לשנות לפי העסק שלכם
הכול פתוח. רוצים קטגוריות אחרות, עוד עמודה, צבעים משלכם או תחזית אחרת? כותבים ל-Claude מה רוצים, והוא משנה בשבילכם.

## חשוב לדעת
אנחנו לא רואי חשבון ולא יועצי מס. הכלי רק מסדר ומציג לך את המידע שלך. הוא רץ על ה-AI שלך ועל המחשב שלך, והקבצים שלך לא מגיעים אלינו. האחריות על הנתונים, על הדיווח ועל מה שנשלח לרואה החשבון היא שלך בלבד. כל החלטה מקצועית עוברת דרך רואה החשבון שלך.

## פרטיות
הקבצים נשארים אצלכם. Claude קורא אותם כדי לבנות את הדוח, כלומר התוכן נשלח למודל. סיסמאות ופרטי כניסה לבנק לא צריך ולא נותנים.
זה כלי עזר ולא ייעוץ מס: מה עסקי ומה פרטי מחליטים אתם, ובמקרה של ספק רואה החשבון.
